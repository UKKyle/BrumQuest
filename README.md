# BrumQuest

Shared, installable Birmingham city-centre and canal photo-hunt PWA.

- GitHub Pages hosts the static PWA.
- Supabase stores linking codes, shared progress and private capture images.
- Realtime broadcast plus periodic refresh keeps linked phones in sync.
- Live GPS never leaves the user's phone.
- OpenStreetMap powers the in-app map and walking-route fallback.

## iPhone installation
Open the published Pages URL in Safari → Share → Add to Home Screen.

Deployment trigger: complete GitHub Pages build with shared Supabase backend.
